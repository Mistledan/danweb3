# Portfolio

Next.js 14, Tailwind CSS and Framer Motion.

## Run locally
    npm install
    npm run dev

Open http://localhost:3000

## Make it yours
Edit `lib/data.ts` (name, email, links, skills, projects). Colours live in `tailwind.config.ts`.

## Deploy free on Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com, choose Add New > Project, and import the repo.
3. Click Deploy. Vercel detects Next.js automatically.
